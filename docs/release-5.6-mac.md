## Mac 版 5.6

[下载 Mac 5.6 安装包](https://github.com/whykang/ssts/releases/download/v5.6/ssts-mac-5.6.dmg)

支持 Apple 芯片和 Intel Mac，最低 macOS 14.6。打开 DMG，将“随身听书”拖入“应用程序”。本包使用本地签名，未经过 Apple 公证。

- 新增 MCP 插件开发：局域网或本机连接 AI，制作草稿、校验、测试、安装、备份恢复和导出 ZIP；内置四端通用开发指南与完整代码示例。
- 云同步增加每集进度、完成状态和手动封面；可选同步插件，默认关闭，支持高版本合并、删除同步及手动重新导入恢复。
- 自动续播下一集从头播放，手动选集恢复独立进度；已听完章节支持从头重播，目录显示每集收听状态。
- 支持 WMA 播放、拖动和断点恢复，改进换集及低采样率音频兼容性。
- 自定义定时关闭时长，优化搜索验证、网盘自动封面更新；保留手动封面选择。
- 设置页横向铺满，播放页支持查看目录和加入书架。

插件删除同步需要其他设备更新到支持该功能的版本。插件包仍从应用的插件页导入。
